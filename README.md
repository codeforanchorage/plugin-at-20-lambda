# plugin-at-20-lambda
Sends sms reminders to Alaska residents to plug in their cars when it's cold

Install [cdk cli tool](https://docs.aws.amazon.com/cdk/v2/guide/cli.html):
```
npm install -g aws-cdk
```

```
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

[Bootstrap AWS environment](https://docs.aws.amazon.com/cdk/v2/guide/getting_started.html#getting_started_bootstrap)
